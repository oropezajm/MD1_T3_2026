Introducción al Álgebra Booleana

El álgebra de Boole es la herramienta matemática fundamental empleada para el análisis y diseño de circuitos de sistemas digitales. A diferencia del álgebra ordinaria, opera exclusivamente sobre variables discretas binarias.

Álgebra Ordinaria
  • Trabaja con el conjunto de los números reales ($\mathbb{R}$).
  • Incluye operaciones como suma, resta, multiplicación, división, fracciones, decimales, raíces cuadradas y números negativos.
  • Las variables pueden tomar infinitos valores continuos.
Álgebra Booleana
  • Las constantes y variables sólo pueden adoptar dos valores posibles: 0 ó 1.
  • Los valores 0 y 1 no representan cantidades numéricas, sino estados o Niveles Lógicos de Voltaje (ej. 0V = LOW = 0, +5V = HIGH = 1).
  • NO existen: fracciones, decimales, números negativos ni raíces cuadradas.
  • Solo existen 3 operaciones básicas fundamentales: AND, OR y NOT.

¿Qué es una Tabla de Verdad?

Una tabla de verdad es un método formal para describir el comportamiento de salida de un circuito lógico para cada una de las combinaciones posibles en sus entradas. Permite definir sin ambigüedad la función lógica deseada.

Precedencia de Operaciones Lógicas

Para resolver o evaluar expresiones booleanas correctamente sin ambigüedad, es imprescindible conocer el orden estricto de ejecución de las operaciones.

1° Prioridad: Paréntesis

Toda expresión encerrada entre paréntesis se evalúa primero. Modifica el orden predeterminado.

2° Prioridad: Operación NOT / AND

Si no hay paréntesis, la operación AND (producto) se realiza antes que la operación OR.

3° Prioridad: Operación OR

La suma lógica (OR) se ejecuta al final salvo que se altere por agrupamiento.

Ejemplo de Interpretación: La expresión A · B + C se interpreta estrictamente como (A · B) + C, ejecutando el producto $A \cdot B$ antes de sumar $C$.
